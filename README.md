# 🎬 Netflix Data Analysis

## 📌 Project Overview

This project explores the Netflix dataset to uncover trends and patterns
in movies and TV shows available on the platform.

The analysis focuses on content types, genres, ratings, release years,
countries and other characteristics of Netflix content.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## 📊 Analysis Performed

- Movies vs TV Shows
- Content distribution by year
- Most common genres
- Content ratings analysis
- Country-wise content distribution
- Trends in Netflix content
- Data visualization
